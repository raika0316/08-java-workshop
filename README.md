## 1. デバッグの練習に使うファイル

[src/Main.java](src/Main.java) は、デバッグ操作を試すための小さなプログラムです。

VSCode の Java 拡張（Extension Pack for Java）を使って、次を試してみてください。

- 行番号の左をクリックして **ブレークポイント** を置く
- **実行とデバッグ**（左のアイコン、または `F5`）で止める
- 止まった位置で **変数の値** を確認する
- **ステップ実行**（`F10` / `F11`）で1行ずつ進める

> このあとの図書館管理システムを作るときは、`src/Main.java` を書き換えても構いません。
> デバッグの練習が終わってから進めてください。

## 2. 図書館管理システム（メイン演習）

スライドの **要件定義・クラス設計** をもとに、**自分で一から** 作成します。
`src` の下に自由にファイルを追加して構いません。

### 作るもの（概要）

- 図書館で管理している本の **検索・貸出・返却・一覧表示・終了** を行うコンソールアプリ
- 本が持つ情報：ID / タイトル / 著者名 / 状態（貸出可能・貸出中）

### 忘れずに考えること（エラー処理）

- 存在しないメニュー番号を入力した場合
- 存在しないタイトルを検索した場合
- 存在しないIDを貸出／返却しようとした場合
- 貸出中の本を貸出そうとした場合
- 貸出していない本を返却しようとした場合

### コンパイルと実行

ファイルを複数に分けた場合は、まとめてコンパイルします。

```bash
cd src
javac *.java
java Main
```

### 日本語が文字化けするとき

キーボードから読み取った日本語が `繧ｳ繝ｼ繝偵�ｼ` のように化けることがあります。
`Scanner` に文字コード（UTF-8）を指定すると直ります。

```java
import java.io.InputStreamReader;
import java.nio.charset.StandardCharsets;
import java.util.Scanner;

// 文字化けする書き方
Scanner scanner = new Scanner(System.in);

// 文字化けしない書き方
Scanner scanner = new Scanner(new InputStreamReader(System.in, StandardCharsets.UTF_8));
```

## 3. コードレビュー

書いたコードを、他のメンバーと見せ合います。次の3つの観点で確認してみてください。

| 観点 | 見るところ |
|---|---|
| **可読性**（読みやすさ） | 変数やメソッドの名前、コメントが十分に書かれているか |
| **仕様を満たしているか** | 要件定義で指定された内容を網羅できているか |
| **安全性** | 異常なデータなどがあった際にもエラーを起こさず処理ができるか |
